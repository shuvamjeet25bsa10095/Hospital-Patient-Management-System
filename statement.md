# Project Statement

## Problem Statement
Manual patient tracking in hospitals causes errors and delays. This app digitizes basic CRUD for quick access.

## Scope
Console-based, in-memory storage. Covers 5 core operations. Expandable to file/DB later.

## Target Users
Hospital staff (admins/nurses) – simple menu for non-tech users.

## High-Level Features
- Patient CRUD via menu loop.
- Search with validation.
- Table display using loops.
