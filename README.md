# Hospital Patient Data Management System

## Overview
A beginner-friendly console app to manage hospital patient records. Handles add/view/search/update/delete using Python basics like loops and lists.

## Features
- Add new patients with ID, name, age, condition.
- View all in a table.
- Search by ID.
- Update or delete records.
- Error-proof inputs.

## Technologies/Tools Used
- Python 3.x (no extras needed).
- Built with lists, dicts, while/for loops, try-except.

## Steps to Install & Run
1. Clone: `git clone https://github.com/yourusername/hospital-patient-manager.git`
2. Open terminal in folder.
3. Run: `python main.py`
4. Follow menu!

## Instructions for Testing
- Add 2-3 patients.
- View/search to check.
- Update one, delete another.
- Data is in-memory (resets on restart).
